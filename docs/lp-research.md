# Uniswap LP 历史研究

这是规则参数校准与离线事件回放，不是对大模型微调。当前不向运行中的 Agent 写入参数，也不操作钱包。本轮实际链上训练受历史数据访问阻塞；尚无真实胜率提升结论。

## 数据与入口

预先固定 Ethereum 主网三个成熟 V3 池，避免根据回测收益挑池：

| 池 | 合约 | tick spacing |
| --- | --- | ---: |
| WETH/USDC 0.05% | `0x88e6a0c2ddd26feeb64f039a2c41296fcb3f5640` | 10 |
| WETH/USDC 0.3% | `0x8ad599c3a0ff1de082011efddc58f1908eb6e6d8` | 60 |
| USDT/USDC 0.01% | `0x3416cf6c708da44db2624d63ea0aaef7113527c6` | 1 |

三个池均以 token0 USDC 为报价、token1 为基础币。两个 ETH 池高度相关，不能算两个独立市场；采用当前仍存续的池存在幸存者偏差，不代表所有 Uniswap 池、其他网络、V2 或 V4。

只采集已完整结束的 30 个 UTC 日。2026-11-04 运行时窗口为 2026-10-05 00:00:00 至 2026-11-04 00:00:00 UTC，不包含 11 月 4 日。每池必须完整 720 小时，同时读取 720 个 USDC/USD 小时价格用于手续费换算。

配置 `.env` 的 `THE_GRAPH_API_KEY`，在有网络的环境执行（密钥不要提交）：

```sh
node --env-file=.env --import tsx server/research/cli.ts collect data/uniswap-2026-11-04 2026-11-04
npm run research -- train data/uniswap-2026-11-04/history.json data/uniswap-2026-11-04/run-01
```

`collect` 可省略结束日期，默认当前 UTC 日界线。普通 `npm run research` 不自动读 `.env`，可先通过环境变量配置密钥。输出目录必须不存在、父目录需已存在；拒绝覆盖已有实验。网络、授权、schema 或数据完整性失败时退出，不降级生成行情。

使用 [Uniswap 文档所列的 V3 Mainnet subgraph](https://developers.uniswap.org/docs/ecosystem/subgraphs/overview) 与 [The Graph 的 Bearer header 认证](https://thegraph.com/docs/en/subgraphs/querying/from-an-application/)。该索引部署不是可永久假设有效的协议保证；失效时需核对新的部署及 schema，不能仅换 URL 后继续相信结果。代码固定部署 ID，以免误接其他链。

先取得索引头，再退后 64 个区块冻结全部查询。64 个确认不等于 Ethereum 最终性保证。原始小时字段、池元数据、USDC 报价、subgraph 部署、区块号/哈希/时间、获取时间一并落盘；报告包含数据 SHA256。未通过独立 RPC 交叉验证，来源标签和摘要是追溯信息，不能证明文件从未被伪造。

数据摘要按解析后的 JSON 紧凑序列化计算，不是带缩进的文件字节摘要。校准文件另记研究实现及所依赖估值/原策略源码的摘要和 Node 版本，方便识别代码变化后的不同实验。

校验池地址、token 地址与 decimals、fee tier、时间连续性、OHLC 边界、正流动性、fees/volume 一致性、索引错误和覆盖时间；用 sqrtPrice 核验价格方向。缺少小时或低于 720 条时拒绝继续，不前向填充，不把当前 APR 当历史手续费。

## 决策与事件时序

`server/research/replay.ts` 复用现有集中流动性估值函数，并对回放区间做 tick 对齐。现有规则基准调用真实 `rulePlan` 和 `strategyCandidates`：越界就建议重新居中，相对半宽度限制为 2%–40%。所以稳定币初始窄区间首次调仓会扩大到至少 2%，如实保留当前逻辑。

新候选只有越界事件才可能调仓：

1. 连续 2 或 4 个小时收盘越界，且距前次调仓至少 6 或 12 小时。
2. 取过去 24 个小时对数收益的波动率，按 24 小时尺度和 1.5 / 2.5 / 4 倍系数确定区间；ETH 半宽度限 0.5%–20%，稳定币限 0.05%–2%。
3. 用过去 24 小时池手续费与活跃流动性估算新范围份额，以 50% 有效时间假设计算费用覆盖；不足预计调仓成本的 2 或 4 倍则继续等待。它是费用回收启发式，不是净收益预测。
4. 收盘只形成待执行事件，下一小时开盘执行；目标区间与触发价在决策时冻结。恢复原区间、开盘偏移超过 1%、成本超过本金 30 bps、预计份额超过 1% 时取消。不会使用下一小时高低价决定此前交易。

只使用过去数据选动作，未来 OHLC/手续费仅用于之后的损益结算。小时数据无法还原实时 5 秒触发、小时内价格路径和重组，因此现有规则对照也是小时采样近似。首个区间采用相同规则：ETH ±5%，稳定币 ±0.1%，实际边界向 tick 网格外扩。

## 训练、隔离测试与胜率

固定前 21 天作为校准区：第 1–7 天预热，第 8–14、15–21 天分别做向前验证。共有 24 组参数，三个池共用一组；不为每池分别拟合。每组在手续费折半和高成本两场景评估，取较差场景得分。得分为相对静态 LP 的加权平均净收益百分点，减去 0.25 × 超额最大回撤百分点；ETH 两池各 25%，稳定币 50%。最优训练分数不为正时回退静态 LP。

先保存 `calibration.json`，冻结参数、候选排序、训练数据摘要和时间边界，再评估最后 9 天。最终测试不重新选参数。若看完测试再修改策略，原测试已成为开发数据，必须另取未接触的未来窗口才能宣称新样本外结果。仅 30 天不能证明跨市场周期有效。

对照静态 LP、当前规则、同初始双币数量持有不动。每池独立模拟 10,000 USDC；组合净值按 25% / 25% / 50% 加权，不把三个账户误报成一个账户按这些权重分配资金后执行的效果。真实小账户的固定 gas 占比会不同。

胜率 = 扣费后连续净值中，每日收益率超过静态 LP 的 UTC 日数 / 9；平局保留在分母且不算胜。另报胜现有规则/持币日数、绝对盈利日数、累计净收益、最大回撤、手续费、总成本、调仓次数、完整在区间小时比例。9 天是 9 个时间窗口，不是 27 个独立样本；不对它做显著性承诺，不年化一个月的结果。

## 收益与成本的边界

- 本金按 V3 集中流动性曲线重估，包含资产价格风险及再平衡导致的资产构成变化。
- 仅当整小时 OHLC 全在范围内，计入 `池小时手续费 / USDC的USD价 × 模拟L/(池末小时活跃L+模拟L)`。跨界小时手续费记零。池末流动性不能代表整小时平均值，因此该近似也不构成严格收益下界。
- 手续费作为 USDC 现金记账且不复投，未模拟手续费币种库存及领取兑换成本；没有逐笔 `feeGrowthInside`、协议抽成和动态 tick 流动性。真实精确评估需交易级数据与历史 tick/fee-growth 状态，不能从小时 OHLC 唯一推出。
- 入场、调仓成本 = gas + 全部本金 × 滑点 bps，保守计全部本金；退出按双币取回只收 gas。持币基准从相同初始币种比例开始，不支付 LP 入退场成本。最终一天计退出成本。
- 基准 gas 5 USDC、滑点 5 bps；高成本场景 gas 15 USDC、10 bps。它们是场景假设，不是历史 gas 观测。手续费分别按 100%、50%、0%；高成本场景按 50%。零手续费场景不改变已冻结的策略参数。
- 1% 流动性份额限制用于约束小参与者近似，未模拟价格冲击、JIT 流动性、MEV、失败交易 gas 或排序变化。超过适用范围时拒绝输出结果。

因此，即便真实数据模型中的胜率改善，也只支持继续验证该候选；不会自动替换实时 Agent，更不能将 Ethereum 参数直接应用到现有 Base、BSC 或 Robinhood 仓位。

## 结果与验证

`calibration.json`：校准排序、训练摘要、冻结参数。`report.json`：来源与摘要、各场景全部逐小时净值、逐次调仓、事件原因、对照结果。`report.md`：可读汇总。

合成输入的 `kind` 必须是 `synthetic-verification`、`subgraphId` 必须为 `null`，其余字段采用同一数据结构，仅能通过以下入口演练：

```sh
npm run research -- verify data/research-verification/history.json data/research-verification/run-01
```

`train` 拒绝合成来源，`verify` 拒绝链上来源，所有合成报告标题明确标记“不是链上训练结果”。按项目规则不新增业务单测；用现有测试、构建和隔离 CLI 实际运行验证流程。

2026-11-04 的实际状态：外部历史 API 在当前执行环境中 DNS 访问失败，网页工具也未取得完整小时序列，且未配置 `THE_GRAPH_API_KEY`。本地已有监控历史仅覆盖 2026-09-07 约一小时，不满足本次近月需求。实际 `collect` 命令已验证会明确失败，不生成伪造行情；真实采集、校准与样本外测试仍未完成。

隔离合成运行已覆盖 3 池 × 720 小时、24 组参数和 4 个最终成本场景；另运行变更测试期、报价取倒数、恒价零手续费、小时缺失及错误训练入口。修改最后 9 天不改变校准排序与参数，恒价无费时回退静态且仅扣预设入退场成本。演练输出位于 `data/research-verification-20261104/`，均带合成标记；原 `data/lp-sentinel.json` 摘要保持一致。

`npm run build` 通过，保留原有 bundle 超过 500 KB 提示。`npm test` 为 64 通过、1 失败；已有 `static-fallback` 用例因沙箱 `listen EPERM` 无法开端口，与此前基线一致。未验证真实 The Graph 查询响应、逐笔链上手续费或实盘收益。
